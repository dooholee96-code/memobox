# 메모함

내 기기에 저장되는 개인용 메모 앱입니다. **클립보드**(자주 쓰는 글을 바로 복사)와 **세컨드브레인**(PARA + 제텔카스텐으로 지식 쌓기) 역할을 같이 합니다.

- 서버도, 회원가입도 없습니다. 옵시디언처럼 메모는 **지금 쓰는 기기 안에만** 저장됩니다.
- 인터넷이 없어도 열립니다. 폰·PC 홈 화면에 앱처럼 설치할 수 있습니다.
- 마크다운(.md)으로 내보낼 수 있어서 언제든 옵시디언으로 옮길 수 있습니다.

## 쓰는 법: 칸 하나로 적고, 찾고, 복사

화면 맨 위의 **입력칸 하나**가 전부입니다.

| 하고 싶은 것 | 동작 |
| --- | --- |
| 적기 | 칸에 적고 **저장** (PC는 Enter). 어디에 둘지는 안 정해도 됨 → 📥 받은함 |
| 복사해 둔 것 담기 | **📋 클립보드 저장** 한 번 |
| 웹·앱에서 담기 | 공유 → 메모함 (편집 화면 없이 바로 저장) |
| 찾기 | 같은 칸에 짧게 적으면 아래 목록이 바로 걸러짐. `#태그` `+프로젝트` `-빼기` 초성 `ㅁㅅ` |
| 자주 쓰는 글 복사 | 📌 고정한 메모는 맨 위 줄에 — **누르면 바로 복사** (둘째 줄부터, 링크 메모는 주소) |
| 내용 보기 | 카드를 누르면 그 자리에서 펼쳐짐 (화면 이동 없음) |
| 고치기 | 펼친 카드의 ✏️ 편집 → 다 쓰면 ‘완료’ 또는 뒤로 가기 |

### 키워드 저장소처럼 쓰기

한 줄에 `키워드: 짧은 설명` 으로 적으면 됩니다. 예) `積読: 사 놓고 안 읽은 책`

- 목록·궁전에는 **키워드**가 크게, 설명은 작게 보입니다.
- **복사**하면 키워드만 복사되고, 알림 줄의 **🔎 검색**을 누르면 바로 구글에서 찾습니다.
- `[[키워드]]` 로 다른 메모를 이을 수 있습니다.

### 🏛 궁전 보기

위쪽 🏛 버튼을 누르면 큰 캔버스 하나에 방(📥 입구 · 📚 자료 · 🌱 영역 · 🎯 프로젝트)이 펼쳐집니다. 마지막에 보던 화면(목록/궁전)을 기억합니다.

- 키워드를 **한 번 누르면 복사** (→ 🔎 검색 / 열기)
- 새로 저장한 키워드는 **입구**에 놓입니다. **끌어서 다른 방에 넣으면** 그게 곧 정리입니다 (폰은 꾹 누른 뒤 끌기)
- 한 번 놓인 자리는 앱이 다시 섞지 않습니다. 자리로 기억하게 하려는 것입니다
- 손가락 두 개(또는 마우스 휠)로 확대·축소, 끌어서 이동, 방을 두 번 누르면 그 방으로. ⤢ 는 전체 보기
- 위 칸에 찾을 말을 치면 맞는 키워드만 밝아지고 그쪽으로 이동합니다

저장할 때 쓰는 짧은 명령:

- `#태그` — 태그 (하위 태그 `#교육/임용`)
- `+이사` — ‘이사 준비’ 프로젝트로 바로 저장 (앞부분만 써도 됨)
- `!` — 고정
- 본문 안: `[[다른 메모 제목]]` 잇기 · `==형광펜==` 핵심 표시(목록에 먼저 보임) · `- [ ] 할 일`

첫 화면 위쪽에는 꼭 볼 것만 뜹니다: 마감 7일 안의 프로젝트, 받은함이 3개 넘으면 **정리하기**(한 장씩 보고 한 번 눌러 보내기), 2주 넘게 안 본 메모 하나(🔁 다시 보기).

## 참고한 메모 방식

| 방식 | 가져온 것 |
| --- | --- |
| Drafts (먼저 적고, 나중에 정하기) | 열면 바로 입력칸. 저장할 때 위치를 묻지 않음 |
| Notational Velocity / Raycast | 한 칸으로 찾기와 적기를 같이. 클립보드 저장, 고정 메모 한 번에 복사 |
| Logseq·Mem (하루 흐름, 폴더 없이) | 날짜별 흐름(오늘·어제…)이 첫 화면. 분류는 태그·링크로 나중에 |
| 제텔카스텐 (임시 메모 → 정리) | 받은함 = 임시 메모. ‘정리하기’로 한 장씩 자료·프로젝트로 보내거나 버림 |
| Andy Matuschak (촘촘한 링크) | `[[링크]]`, 이 메모를 가리키는 메모, 태그가 겹치는 메모를 펼친 카드에 표시 |
| 티아고 포르테 CODE·PARA·점진적 요약 | 프로젝트·영역·자료·보관 칩, `==형광펜==`이 목록 미리보기에 먼저 |
| Readwise (다시 보여 주기) | 오래 안 본 메모를 하루 하나 첫 화면에 |
| Google Keep | 카드형 목록, 고정 |

## PARA 정리법 (이 앱 기준)

| 칸 | 넣는 것 | 예 |
| --- | --- | --- |
| 📥 받은함 | 일단 담은 것. 나중에 옮김 | 공유로 받은 기사 |
| 🎯 프로젝트 | **끝나는 날이 있는 일**. 마감일·D-day 표시 | 2027 임용 2차 준비, 이사, 학교 축제 |
| 🌱 영역 | **끝이 없이 계속 챙기는 분야** | 수업, 건강, 돈 관리, 집 |
| 📚 자료 | 언젠가 쓸 정보. 태그로 찾음 | 미술 수업 아이디어, 레시피 |
| 🗄 보관 | 끝난 프로젝트, 다 쓴 메모 | |

헷갈릴 때 기준:

- **“끝났다고 말할 수 있는 날이 있나?”** 있으면 프로젝트, 없으면 영역.
- **매년 반복되는 일**(예: 학교 축제, 연말정산)은 둘로 나눕니다. 해마다 쓰는 양식·노하우는 **영역**에, 올해 진행분은 **프로젝트**(`2026 축제`)로 만들고 그 영역에 연결합니다. 끝나면 ✅ 끝냄 → 보관. 내년엔 영역에서 노하우를 보고 새 프로젝트를 만듭니다.
- **여러 프로젝트에 쓰이는 자료**는 자료에 두고 `#태그`나 `[[링크]]`로 잇습니다. 메모를 복사해 두 군데 넣지 않습니다.

## 설치

### 1. 인터넷 주소 만들기 (처음 한 번, GitHub Pages)

1. 이 저장소에서 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: **main** / **(root)** → Save
3. 1~2분 뒤 `https://내아이디.github.io/memobox/` 에서 열립니다.

> 저장소가 공개(Public)여도 메모는 공개되지 않습니다. 공개되는 건 앱 코드뿐이고, 메모는 각자 기기 안에만 있습니다.

### 2. 휴대폰에 설치

- **안드로이드(크롬)**: 주소를 열고 메뉴 ⋮ → **앱 설치**(또는 홈 화면에 추가). 이제 어느 앱에서든 **공유 → 메모함**으로 바로 저장됩니다.
- **아이폰(사파리)**: 주소를 열고 공유 버튼 → **홈 화면에 추가**.
  - ⚠️ 아이폰은 사파리에서 연 것과 홈 화면 앱의 저장 공간이 **따로**입니다. 항상 홈 화면 아이콘으로 여세요.

### 3. 아이폰 공유 메뉴에 넣기 (단축어)

1. **단축어** 앱 → ＋ → 이름 `메모함에 담기`
2. 아래 ⓘ(설정) → **공유 시트에서 보기** 켜기, 받는 형식: URL·텍스트
3. 동작 추가: **URL 인코딩** (입력: 단축어 입력)
4. 동작 추가: **URL 열기** → `https://내아이디.github.io/memobox/?text=` 뒤에 ‘URL 인코딩된 텍스트’ 변수
5. 이제 사파리·유튜브 등에서 공유 → **메모함에 담기**

### 4. PC 크롬에서 담기

메모함 → ⚙️ 백업·설정 → **📎 메모함에 담기** 버튼을 북마크바로 끌어다 놓습니다. 아무 웹페이지에서 누르면 제목·주소(드래그해 둔 글이 있으면 그 글도)가 저장됩니다.

## 기기 사이 옮기기 · 백업

지금 버전은 자동 동기화가 없습니다(옵시디언 기본과 같음).

- 다른 기기로 옮길 때: ⚙️ → **전체 백업(JSON)** → 그 파일을 다른 기기에서 ⚙️ → **가져오기**. 같은 메모는 더 최근 것이 남습니다.
- 폰에서 백업하면 공유 창이 떠서 구글 드라이브·카카오톡 나에게 등으로 바로 보낼 수 있습니다.
- 옵시디언 노트(.md)도 여러 개 골라서 가져올 수 있습니다.

## 다음에 붙일 수 있는 것

- **자동 동기화**: 메모는 지금처럼 기기에 두고, 바뀐 것만 Supabase(무료)나 구글 드라이브 파일과 주고받는 방식. 로컬 우선은 그대로 유지
- 크롬 확장(선택 영역 캡처), 웹페이지 본문 자동 저장
- 그래프 보기(메모 연결 지도)

## 개발

- 빌드 도구 없음. `index.html` + `style.css` + `js/`(ES 모듈) 그대로 배포
- `js/core.js` 순수 함수(검색·태그·링크·마크다운·ZIP), `js/db.js` IndexedDB, `js/app.js` 화면
- 테스트: `npm test` (Node 20 이상, 설치할 것 없음)
- 로컬 실행: `python3 -m http.server` 후 `http://localhost:8000`
- 앱 파일을 바꾸면 `sw.js`의 `CACHE` 이름(버전)을 올려야 설치된 앱이 새 파일을 받습니다
